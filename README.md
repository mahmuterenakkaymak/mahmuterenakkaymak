### ERP × Local AI

I'm Mahmut Eren, an ERP Project Specialist in Istanbul building **local-first AI** for real business workflows on my
own hardware. Business Administration graduate (Istanbul University), now doing an MIS master's (thesis track) at the
same university.

**How I build:** the deterministic core lives in SQL and code; the LLM is the language layer. A model never owns a
critical number - totals, VAT, scores are computed and verified. Customer data stays on machines I control.

#### What I work on

- 🏹 **[MERGEN](https://github.com/mahmuterenakkaymak/mergen)** - a Turkish-speaking AI assistant and a hybrid
  software pipeline (Claude plans and reviews, a local Qwen model writes the code) on a single RTX 5090.
- 🧾 **Okur** - receipt and handwriting OCR on a local vision model (Qwen3.8-27B): photo -> structured JSON with
  VAT and total checks - a clean JSON output any ERP or accounting integration can consume. Plus a Turkish OCR
  fine-tuning pipeline.
- 🗄️ **Natural language -> T-SQL** over an ERP schema, with RAG over the database structure and business rules.
